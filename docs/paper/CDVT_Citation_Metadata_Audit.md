## Corrections Applied

1. Reference [5] was corrected from 2024 and pages 461-474 to PVLDB volume 16,
   issue 3, 2022, pages 461-469, DOI 10.14778/3570690.3570696.
2. Reference [13] was corrected from 2024 with no pages to NeurIPS volume 36,
   2023, pages 29851-29874, DOI 10.52202/075280-1300.
3. Verified DOI fields were added to references [1], [3], [4], [5], [10], and
   [13].
4. Proceedings page ranges were added to references [8] and [11].
5. References [14]-[20] were added to cover continuous-time temporal graph
   learning, event-based graph representations, transaction-node AML models,
   temporal message passing, and the closest line-graph multi-view AML method.
6. The novelty wording was narrowed after identifying LineMVGNN: CDVT is not
   claimed as the first multi-view transaction model.
